PA Code Field Mapping (ISO 23386):

PA CodeField NameDescription
PA001dictionaryProperty dictionary assignment
PA002version_numberProperty version
PA003revision_numberProperty revision
PA004data_typeData type (string, integer, real, etc.)
PA005unit_of_measurementPhysical unit
PA007value_domainAllowed value range
PA008physical_quantityPhysical quantity reference
PA011classification_systemClassification system used
PA012classification_referenceClassification reference
PA016statusProperty status (active, deprecated, etc.)
PA017registration_authorityRegistration authority
PA018registration_dateRegistration date (YYYY-MM-DD)
PA021country_of_originCountry of origin
PA022countries_of_useCountries of use
PA023creators_languageCreator's language

Extended Data Storage:

  • ISO 16757 fields → stored in extended_attributes JSON field
  • Identifier fields (id_, code_, ref_, guid) → stored in metadata.identifiers
  • Calculation fields (calc_, formula_, method_) → stored in metadata.calculations
  • PA code data → stored in metadata.pa_code_data for reference
  • Other fields → stored in metadata.custom_attributes

Multi-language Support:

Property names and definitions will be automatically created from name and definition columns.
