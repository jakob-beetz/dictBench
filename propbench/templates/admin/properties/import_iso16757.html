ISO 16757 Import Guide

This import function is designed specifically for ISO 16757 compliant CSV files with PA code mapping.

  • Supported Fields: Property ID, Property type, UnitNo, Status, multilingual Names/Definitions
  • Field Mapping: All ISO 16757 fields preserved in extended_attributes, PA codes in metadata
  • CSV Format: Supports both comma (,) and semicolon (;) delimited files
  • Encoding: UTF-8 with BOM support for international characters
