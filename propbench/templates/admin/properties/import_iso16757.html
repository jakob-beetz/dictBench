ISO 16757 Import Information:

Import properties from ISO 16757 compliant CSV files with full PA code support

Expected Fields:

Core Fields (Required):
  • data_type or DataType - Property data type
  • unit or Unit - Unit of measurement
PA Code Fields (Optional):
  • name, Name - Property name
  • definition, Description - Property definition
  • status - Property status
  • version_number, revision_number - Versioning
  • classification_system, classification_reference - Classification
  • physical_quantity - Physical quantity reference
  • country_of_origin, language - Localization
ISO 16757 Specific Fields:
  • iso_class_id, standard_reference - ISO classification
  • property_definition, class_definition - Extended definitions
  • Any field containing 'iso', '16757', 'standard', or 'class'

Mapping Information: All fields are automatically categorized and stored according to PA code compliance and ISO 16757 standards.

Import Process:

  1. CSV data is validated and parsed
  2. PA001-PA025 compliant fields are mapped to Property model
  3. ISO 16757 specific attributes are stored in extended_attributes
  4. Custom identifiers and metadata are preserved in metadata
  5. PropertyName and PropertyDefinition records are automatically created
  6. Import is performed within a database transaction
  7. User tracking is applied to all imported/updated records
  8. Duplicate properties (same dictionary + data_type + unit) are updated, not duplicated

Data Categorization:

Field PatternStorage LocationExamples
PA Code Fields Direct model fields + metadata.pa_code_data data_type, unit, status, version_number
ISO/Standard fields extended_attributes iso_class_id, standard_reference, class_definition
Identifier fields metadata.identifiers id_internal, code_legacy, ref_external, guid
Calculation fields metadata.calculations calc_method, formula_base, method_standard
Other fields metadata.custom_attributes custom_field, additional_info, notes

Transaction & Rollback:

This import uses Django's atomic transaction system. If any error occurs during import, all changes are automatically rolled back. With django-reversion enabled, you can also view detailed change history and perform granular rollbacks.

Performance Notes:

  • Large files (>1000 rows) are processed in chunks
  • Existing properties are updated efficiently using database constraints
  • Related PropertyName and PropertyDefinition records are created automatically
  • All import metadata is preserved for audit trails
