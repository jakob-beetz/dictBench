Import Process:

  1. CSV data is validated and parsed
  2. Core fields are mapped to PropertyGroup model
  3. ISO 16757 specific attributes are stored in extended_attributes
  4. Custom identifiers and metadata are stored in metadata
  5. Import is performed within a database transaction
  6. User tracking is applied to all imported/updated records
  7. Duplicate names within the same dictionary are updated, not duplicated

Data Categorization:

Identifier fields metadata (as identifiers) id_internal, code_legacy, ref_external, guid
Calculation fields metadata (as calculations) calc_method, formula_base, method_standard
Other fields metadata custom_field, additional_info, notes

Rollback Information:

This import uses Django's transaction system. If any error occurs during import, all changes are automatically rolled back. For advanced rollback capabilities, install django-reversion to track individual changes.
