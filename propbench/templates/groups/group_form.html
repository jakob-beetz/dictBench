  • Class - Classification grouping
  • Domain - Domain-specific properties
  • Functional - Function-based grouping
  • Collection - Property collections
  • Template - Template groups
Hierarchical Structure
  • Groups can have parent groups
  • Creates tree-like organization
  • Circular references prevented
  • Property inheritance supported
